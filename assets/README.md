# Assets Folder

## Brand Header Image

**Place your TAP2LOCK header image here:**
- Filename: `tap2lock-header.png` or `tap2lock-header.jpg`
- Recommended size: 1200px x 200px (or similar aspect ratio)
- Should include: TAP2LOCK logo and "T2L Raffle - Spin to WIN" text

## Current Header Reference
Your header should look like:
- TAP2LOCK logo with blue "2" 
- Black text with phone/NFC icon
- Subtitle: "T2L Raffle - Spin to WIN"

## File to Replace
The app will automatically use: `assets/tap2lock-header.png`

If you use a different filename, update in `index.html`:
```html
<img src="assets/YOUR-FILENAME.png" alt="TAP2LOCK Raffle">
```

🎡 Prize Wheel

Choose how to run the app:

📱 Installation Options:

  • File Mode: Opens index.html directly - works immediately but can't install as PWA
  • Server Mode: Requires running START_SERVER.bat first - enables full PWA features

✅ What Works Offline:

  • ✅ Spinning wheel animation
  • ✅ Add/delete prizes
  • ✅ Save prizes locally
  • ✅ Winner selection
  • ✅ Works on iOS, Android, Desktop

🚀 To Deploy for Mobile:

  • 1. Upload files to GitHub Pages, Netlify, or Vercel (free)
  • 2. Open the URL on your phone
  • 3. Add to Home Screen (iOS) or Install (Android)
  • 4. App works 100% offline after first load!

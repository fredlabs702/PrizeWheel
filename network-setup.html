💾 Offline Capability

How it works:

  1. First visit: Device downloads app from your laptop
  2. Service Worker caches all files locally on device
  3. Future visits: App loads from device cache (instant!)
  4. Data saved: All registrations stored in browser LocalStorage
  5. Works offline: Turn off WiFi, app still functions perfectly

⚠️ Cache clearing: If you update the app, devices need to press Ctrl+Shift+R (or clear browser cache) to get new version.

🔧 Troubleshooting

  • Can't connect? Check firewall - run START_NETWORK_SERVER.bat as Administrator
  • IP changed? Restart router resets IP - regenerate QR code
  • Slow loading? First load downloads all files, then cached
  • Old version showing? Clear browser cache or hard refresh
